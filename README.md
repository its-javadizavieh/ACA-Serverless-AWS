# ACA-Serverless-AWS

**Serverless su AWS** - Complete course materials for building serverless applications on Amazon Web Services using Lambda, API Gateway, DynamoDB, Step Functions, and SAM.

## 📚 About This Repository

This repository contains comprehensive educational materials for a course on **serverless computing on AWS**, including hands-on labs designed for practical cloud computing learning. Lectures 10-19 form a 40-hour block of ten 4-hour sessions. The course covers the full serverless stack from Green IT foundations through real-world orchestration and Infrastructure as Code.

## 📖 Topics Covered

1. Green IT - Smart Working, Smart Grid, economia circolare
2. Introduction to serverless computing and cloud-native architectures
3. Serverless fundamentals and architectural comparison
4. Real-world use cases and cost analysis
5. Limitations, anti-patterns, and best practices
6. AWS Lambda - functions, handlers, cold/warm starts
7. Lambda triggers, event sources, and multi-language support
8. Lambda resources, memory, timeout, and monitoring
9. Security - IAM roles, policies, least privilege
10. Amazon API Gateway - REST APIs, proxy integration, CORS
11. Advanced integration, Lambda authorizers, Cognito
12. API versioning, stages, and monitoring
13. Caching, X-Ray tracing, and review
14. Amazon DynamoDB - tables, keys, queries, scans
15. DynamoDB Streams, S3 integration, GSI
16. S3 triggers, CSV import pipelines, persistence
17. TTL, backups, Point-in-Time Recovery
18. AWS Step Functions - state machines, Workflow Studio
19. Error handling, Retry, Catch, fallback states
20. Multi-service orchestration and direct SDK integrations
21. AWS SAM - templates, CLI, local testing, deploy
22. CloudFormation, automated deployments, CloudWatch
23. Cost governance, final exam, and course wrap-up
